# 🔒 Password Strength Checker in Python  

**English:**  
A simple Python script that checks if user passwords are strong. The user enters 5 passwords, and each one is tested: if the password length is at least 8 characters, it is considered strong; otherwise, it is weak.  

**Deutsch:**  
Ein einfaches Python-Skript, das überprüft, ob Benutzerpasswörter stark sind. Der Benutzer gibt 5 Passwörter ein, und jedes wird getestet: Wenn das Passwort mindestens 8 Zeichen lang ist, gilt es als stark; andernfalls ist es schwach.

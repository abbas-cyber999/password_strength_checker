# 🔐 Password Strength Checker (Python)

Ein kleines, aber praktisches Python-Tool zur Überprüfung der Passwortstärke.  
Das Programm analysiert mehrere eingegebene Passwörter und bewertet, ob sie die Mindestanforderungen erfüllen.

---

## 🚀 Funktionen
- Benutzer gibt mehrere Passwörter ein  
- Jedes Passwort wird auf folgende Kriterien geprüft:  
  ✔ Mindestlänge  
  ✔ Groß- und Kleinbuchstaben  
  ✔ Zahlen  
  ✔ Sonderzeichen  
- Ausgabe zeigt, ob ein Passwort **stark**, **mittel** oder **schwach** ist
